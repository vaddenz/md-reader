# 文档朗读 Phase 1 验收（v1.9）

> 日期：2026-10-21 · 分支：`tts-read-aloud` · 状态：Phase 1 基本通过（用户初测），音色待 Phase 2
> 设计：[TTS spec](specs/2026-10-21-tts-design.md) · 调研：[浏览器 TTS 调研](research/2026-10-21-browser-tts.md)

## 环境

- 设备：Android 10（首轮 Phase 0 设备）
- 浏览器：Edge Android 139（用户日常浏览器）
- 访问方式：HTTPS（ngrok tunnel 或 GitHub Pages）
- 文档：真实笔记，含代码块、表格、mermaid、中英混排

## 验收项

### 入口与播放

- [ ] `⋯` 菜单中的「朗读」项可见；点击后 2s 内出声。
- [ ] 播放条显示「第 X/Y 句 · 约剩 N 分钟」；播放/暂停图标正确。
- [ ] 当前句有强调色高亮；滚动到视口约 35%。
- [ ] 手动上下滚动后 8s 内不抢滚动；播放条出现「回到当前」。
- [ ] 点「回到当前」能滚回当前句。

### 控制

- [ ] 暂停后再继续：听感能从原位置继续（Edge 原生 pause）。
- [ ] 上一句 / 下一句：切到目标句，不出现双声/吞句。
- [ ] 语速 0.75 / 1.0 / 1.25 / 1.5 / 2.0 切换正常。
- [ ] 睡眠定时：设置后到点，在当前句结束后停止。
- [ ] 关闭播放条：立即静音，进度保存。

### 锁屏 / 前后台

- [ ] 播放中锁屏：当前句播完后暂停（不继续读下一句）。
- [ ] 亮屏回前台：自动继续（或显示「继续朗读」）。
- [ ] 切到其他 App 再回来：行为与锁屏一致，无残留声音。
- [ ] 切换文档 / 标签 / 仓库：旧朗读立即停止，不串音。

### 内容

- [ ] 代码块、mermaid、表格默认跳过；无「const」「flowchart」等乱读。
- [ ] 链接只读文字，不读 URL；图片按 alt 或跳过。
- [ ] `useEffect` 拆成 `use Effect` 后听感可接受；`getVoices` 类似。
- [ ] 标题、列表、引用、长段落顺序正确，无重复朗读。
- [ ] 打开「朗读表格」后，表格按行读；关闭后跳过。

### 语音 / 断点

- [ ] Edge 语音列表为空时，仍用默认语音正常朗读，不显示错误态。
- [ ] 打开「朗读设置」：显示「系统没有返回语音列表，将使用默认语音」；可刷新。
- [ ] 语速/开关设置关闭面板后仍生效；刷新页面后保留。
- [ ] 中途关闭再打开：从上次句子继续；「从头朗读」从第 1 句开始。
- [ ] 读完后再点播放：从第 1 句重新开始（或明确选择继续）。

### 无障碍与稳定性

- [ ] 播放条按钮有可读的 `aria-label`；状态变化有 `aria-live`。
- [ ] 播放条出现时正文最后一段不被遮挡；目录入口在朗读设置里可用，且浮动目录按钮不再遮挡正文。
- [ ] 连续朗读 20 分钟：不卡死、不 OOM、无明显烫手/耗电异常。
- [ ] 快速连点播放/暂停/下一句：不出现双声、卡死、Promise 悬挂。

## 已知限制（Phase 1）

- 音色仍是系统默认；Edge 的 `getVoices()` 返回 0，无法选音色。音质提升留给 Phase 2 的 Matcha 本地包。
- `boundary` 不触发，逐词高亮不可用；当前句为句级高亮。
- `speechSynthesis.paused` 属性不可信；暂停以听感 + `onend` 是否提前触发为准。
- 锁屏/后台不是真正的后台播放：只保证当前句播完再停；亮屏可继续。
- 不在锁屏/通知栏提供 Media Session 控件。

## 结果

2026-10-21：Edge Android 10 + HTTPS 初测，用户反馈「基本 OK」：

- 暂停、继续、取消后立即读正常；
- 锁屏后当前句播完暂停，亮屏可继续；
- 主要遗留：音色仍是系统默认，待 Phase 2 的 Matcha 本地语音包；
- 完整清单中的其他项（选区入口、设置持久化、20 分钟稳定性等）待逐项补齐。

## Phase 2 验收：Matcha zh-en 离线语音包（v1.11）

> 目标设备同 Phase 1（Android 10 + Edge Android 139）；分支 `tts-phase2`。
> 前置：已完成 Spike；正式实现为 OPFS + ModelScope CDN + Worker/Web Audio。

### 下载与存储

- [ ] 阅读页 `⋯` → 朗读 → 展开 → 「引擎」区可见「下载离线语音包」，显示约 140MB。
- [ ] 点击后显示下载进度（文件、字节），可取消；取消后不残留半包。
- [ ] 下载完成后显示「已下载 · 大小 · 版本」，`离线语音包` 引擎按钮可点。
- [ ] 刷新页面后仍显示已下载（OPFS + 元数据持久化）。
- [ ] 「删除离线语音包」后回到未下载状态，引擎自动切回系统语音。

### 本地播放

- [ ] 切到「离线语音包」后播放条显示「离线包」；从当前句继续，不从头开始。
- [ ] 本地播放 10s 内无爆音/断句；与系统语音相比，英文术语可懂。
- [ ] 暂停/继续：从原句内位置继续（AudioContext.suspend/resume）。
- [ ] 上一句/下一句、语速 0.75–2.0 正常；切语速从当前句重播。
- [ ] 睡眠定时、断点续读、跳过代码/表格/mermaid 与 Phase 1 一致。
- [ ] 连续朗读 10 分钟：RTF 能跟上（不出现「合成慢于播放」的长时间停顿）、无明显烫手/耗电异常。

### 离线与回退

- [ ] 飞行模式（模型已下载）下：本地引擎可合成；系统语音/网络语音不可用时不影响本地。
- [ ] 飞行模式（模型未下载）下：显示下载失败提示，系统语音仍可用。
- [ ] 本地引擎初始化失败 / 连续合成失败：自动切回系统语音并提示一次，不静默卡死。
- [ ] 删除模型后，`tts.prefs.engine` 回到 `system`。

### 兼容

- [ ] 不支持 OPFS 的浏览器：离线包区显示不支持说明，系统语音不受影响。
- [ ] CSP 变更后全站无回归：图片、字体、GitHub API、Neon 同步正常。
- [ ] Service Worker 更新后，`tts/runtime` 已缓存；飞行模式刷新后本地引擎仍可初始化。

### 桌面预验证（2026-10-22，Chromium + Playwright）

- 真实下载 ModelScope 模型（约 140MB）→ OPFS → Worker 挂载 → 本地播放、暂停/继续、下一句：通过（18.4s 完成下载 + 首次播放）。
- 单元测试 475 通过；e2e 96 通过（含离线包入口与真实下载手动用例）。
- Android 真机结果待补。
