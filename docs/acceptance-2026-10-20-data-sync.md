# 跨设备同步真机验收清单（v1.7）

> 日期：2026-10-20 · 验收环境：安卓手机 PWA（主屏幕应用）+ 桌面浏览器 / 第二个浏览器 profile。
> 前置：已按 [`docs/sync-neon-setup.md`](sync-neon-setup.md) 启用 Neon Data API、执行初始化 SQL、配置 JWKS 与 CORS，并准备好同一 `sub` 的长期 JWT。
> 通过标准：以下逐项通过；任一项不通过则记录现象与复现步骤后回到修复。
> 设备约定：**A** = 主要使用设备（已有本地数据）；**B** = 第二台设备或另一个干净的浏览器 profile。

## 1. 默认关闭与手动同步

- [ ] 全新配置保存后，状态显示「仅手动同步」，「自动同步」开关为关。
- [ ] 冷启动应用、切换网络（飞行模式 → 联网）、切到后台再回来、修改进度 / 高亮 / 收藏，均**不产生**同步网络请求（可在 DevTools Network / 代理观察）。
- [ ] 上述操作后待同步条数增加，但数据不上传；点击「立即同步」才拉取 + 推送。
- [ ] 打开「自动同步」后，启动 / 联网 / 页面隐藏 / 数据变更恢复自动触发；关闭后再次停止。
- [ ] 「停用」后自动与手动同步都不可用；重新启用后 outbox 保留并可补推。

## 2. 两台设备恢复六类数据

在 A 上准备以下数据，手动同步；在 B 上用同一 URL + 同一 JWT 手动同步：

- [ ] 阅读进度：首页「继续阅读」出现同一文档与相近百分比；打开文档落到对应位置。
- [ ] 文本高亮：B 打开同一文档，黄 / 红高亮位置与原文一致。
- [ ] 收藏：B 首页收藏区出现同一文档，顺序与 A 一致（先收藏在前）。
- [ ] 记忆 SRS：B 的概览「到期」数量与 A 一致；答题调度按同一 `lastAt` 计算。
- [ ] 训练记录：B 的记录页出现 A 的训练明细（题型、得分、点评、用时）。
- [ ] 题库偏好：B 的题库选择与范围筛选与 A 一致；训练题量 / 每日新题保持 B 本机设置，不被覆盖。

## 3. 删除与 reset

- [ ] A 删除一条高亮 → 立即同步 → B 同步后该高亮消失；刷新 / 重启后不复活。
- [ ] A 取消收藏 → 立即同步 → B 同步后收藏消失；B 不会把它推回。
- [ ] B 在拉取前先离线删除同一条高亮，再联网手动同步：不被 A 的旧 upsert 复活（本地墓碑生效）。
- [ ] A「清除训练数据」→ 立即同步 → B 同步后旧 SRS / 训练记录消失。
- [ ] B 在清除后仍带着旧的待推送训练记录联网同步：旧记录不复活（reset 过滤）。
- [ ] A 在 B 清除后重新作答同一题 → 新记录正常同步（晚于 reset）。

## 4. 多仓库

- [ ] 配置同一 Owner 下至少两个仓库；在非当前仓库产生进度 / 高亮 / 收藏 / 训练数据。
- [ ] 点击一次「立即同步」，两个仓库都出现在「仓库结果」，各自拉取 / 应用 / 推送计数合理。
- [ ] B 同步后两个仓库的数据分别恢复，scope 不串（`owner/repo@branch` 不同）。
- [ ] 切换当前仓库不需要额外触发同步；自动同步开启时同样覆盖全部仓库。
- [ ] 某个仓库被旧标签页占用时显示「数据库被占用」，其他仓库仍完成同步。

## 5. 错误文案与恢复

- [ ] 错误 JWT（改一个字符）→ 测试连接 / 同步显示「JWT 无效、已过期或没有权限」，不出现原始响应体或 token。
- [ ] 未执行初始化 SQL（或删除表）→ 显示「同步表不存在，请先执行初始化 SQL」。
- [ ] CORS 未允许当前来源 → 显示「网络不可用，或 Neon CORS 未允许当前站点」。
- [ ] 错误 API URL（404）→ 提示检查接口地址 / 表，而不是静默失败。
- [ ] JWT 临近 30 天到期 → 状态卡黄色提示，不阻断同步。
- [ ] JWT 已过期 → 阻止测试 / 同步并提示重新签发。

## 6. 离线与补推

- [ ] 飞行模式下修改进度、加高亮、收藏、答题：本地功能全部正常，状态为离线，「立即同步」禁用。
- [ ] 恢复网络后：自动同步开启 → 自动补推；自动同步关闭 → 提示手动同步，点击后补推成功。
- [ ] 离线期间关闭应用再打开：待推送条数仍在，联网后不丢失。
- [ ] 同步失败 / 后端 5xx 时阅读、搜索、高亮、收藏、训练均不受影响，outbox 保留。

## 7. 真机（安卓 PWA）

- [ ] 主屏幕 PWA 中完成首次配置、测试连接、保存、立即同步，布局无横向溢出，按钮触控目标正常。
- [ ] 设置首页「跨设备同步」摘要在「未配置 / 仅手动 / 自动 / 失败 / 已停用」间正确切换。
- [ ] JWT 掩码显示；「更换」后输入框为空，取消 / 返回不会误保存。
- [ ] 切到后台再回前台、锁屏解锁后：自动同步关闭时无请求；开启时按策略补同步。
- [ ] 危险区「清除全部数据」二次确认包含跨设备同步配置；执行后回到引导页，Neon 上已有数据不会被删除，重新配置后仍可能拉回。

## 8. 回归

- [ ] 阅读、搜索、收藏、高亮、多标签、记忆助手、设置各页无回归。
- [ ] `npm run typecheck` / `npm test` / `npm run build` / `npm run test:e2e` 全绿。
