## 1. 核心功能

| # | 操作步骤 | 预期 | 结果 |
| --- | --- | --- | --- |
| 1.1 | 打开设置页 → 「阅读外观」→ 正文字号下方点「粗体」 | 预览块正文立即变粗（600）；同一组内「细 / 常规 / 中粗 / 粗体」单选互斥、选中态正确 | |
| 1.2 | 保持「粗体」，进入任意文档 | 正文以 600 字重渲染；标题（h1–h4）字重与改动前一致 | |
| 1.3 | 阅读页 ⋯ → 外观 → 切换「细 / 中粗」 | 面板内可调、URL 不变；当前文档正文实时跟随（300 / 500）；关闭面板后设置页显示同一选择（单源） | |
| 1.4 | 选「粗体」后刷新页面 / 重开应用 | 字重仍为 600（持久化）；清除站点数据后回到默认 400 | |
| 1.5 | 不修改任何外观设置，打开文档 | 正文默认 400，与升级前观感一致 | |
