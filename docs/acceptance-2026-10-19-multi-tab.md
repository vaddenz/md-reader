## 1. 核心路径

| # | 操作步骤 | 预期 | 结果 |
| --- | --- | --- | --- |
| 1.1 | 首页打开文档 A → 阅读页 ⋯ → 文件 → 打开文档 B | B 进入阅读页；顶栏标题右侧出现 ▾；A 仍在（不丢失）。从首页 / 搜索结果 / 继续阅读 / 正文互链 / 上下篇进入文档同样适用 | |
| 1.2 | 点顶栏标题 | 顶栏下方弹出白卡切换器，两行 = 文档标题 + 关闭 ×；当前标签（B）整行浅蓝染底、标题浅蓝加粗（`aria-current`）；点外部或 Esc 关闭 | |
| 1.3 | 滚到 A 中部（约 50%）并等待进度写入 → 切到 B → 再从切换器点 A | 回到 A 阅读页，位置恢复到切走前（误差 ≤5%）；切到 B 时 B 从自己的位置开始 | |
| 1.4 | 切换器中关闭当前标签 A | 自动切到相邻标签（优先右侧，无右侧取左侧）并进入该文档；关闭非当前标签则直接移除、不切页；关闭后切换器保持打开，可连续关闭 | |
| 1.5 | 关闭切换器中的最后一个标签 | 返回首页，标签清空（重开应用也不复活）；从首页重新打开文档后为单标签 | |
| 1.6 | 只有一个标签时点顶栏标题 | 切换器仍可唤出（一行、带关闭 ×），用于关闭最后一个标签；单标签时不显示 ▾，≥2 个标签时 ▾ 出现 | |

## 2. 边界与恢复

| # | 操作步骤 | 预期 | 结果 |
| --- | --- | --- | --- |
| 2.1 | 打开 A、B（当前停在 B，B 有滚动位置）→ 整页刷新 / 从主屏幕重开 PWA | 整页刷新后仍回到 B（当前文档恢复）；PWA 冷启动回首页时切换器仍为 A、B 两行且 B 为激活标签；B 位置按落位语义恢复（误差 ≤5%） | |
| 2.2 | A 已开 → 返回首页 → 从首页 / 搜索 / 文件树 / 互链再次点击 A | 不新增标签，直接聚焦已有 A 标签；切换器中 A 仍只有一行 | |
| 2.3 | 在开发者工具把本地存储 `tabs` 键写成损坏值（如 `garbage`）→ 重开应用 | 启动不被阻塞，标签为空；打开任意文档后切换器只有 1 条 | |
| 2.4 | 让标签指向一个已从仓库删除的文档（同步树后）→ 重启恢复 | 该标签被丢弃，其余标签保留；启动不被阻塞（被丢弃的是当前标签时不会白屏，打开任一保留标签即可继续阅读） | |
| 2.5 | 从首页直接打开文档 → 阅读页点顶栏返回 → 回首页 → 再打开任一已开文档 | 返回首页后标签不清空；再次打开该文档时聚焦原标签，不新开、不丢位置 | |

| # | 操作步骤 | 预期（功能与波1一致，标签切换不改变语义） | 结果 |

| 3.1 | 导航返回：首页 → 文档 → 顶栏返回；阅读页 → ⋯ → 搜索 → 取消；阅读页 → ⋯ → 设置 → 返回；搜索页 → 文档 → 返回 | 均回到进入前的页面（阅读页 → 搜索/设置后返回阅读页；搜索页进文档后返回搜索页且保留查询词）；直接打开 / 冷启动无应用内历史时回首页 | |
| 3.2 | 目录定位：滚到文档中部 → 点悬浮目录按钮 | 抽屉打开时激活章节已在可视区内（居中偏上、无平滑动画）、浅蓝加粗；点条目跳转且 scroll-spy 跟随 | |
| 3.3 | 搜索：⋯ → 搜索 → 输入关键词 → 打开结果 → 回到搜索页再开另一篇 | 结果即时出现；文档按新开/聚焦规则进入标签；命中处浅蓝染底 + 下划线；`?to=` 锚点在目标标签内生效 | |
| 3.4 | 收藏：⋯ → 收藏 → 切换标签 → 回首页 | 星标切换即时生效且按文档独立；切换标签后状态不串；首页收藏区块正确出现 / 消失 | |
| 3.5 | 进度：滚到中部 → 切到另一标签 → 切回 → 退出重开 | 每个标签独立位置；切回与重开均恢复到各自位置（误差 ≤5%）；首页「继续阅读」百分比与该文档一致 | |
| 3.6 | 高亮：长按选区 → 高亮·黄 / 红 → 切换标签 → 刷新 | 即时上色（黄 `#FFF1A8` / 红 `#FFD9D4`）；切换标签、刷新后仍在原位且只属于该文档；清除高亮可用；代码块内仅复制 | |
| 3.7 | 离线：飞行模式重开 PWA | 离线横幅出现；已缓存文档可读，恢复后的标签可正常切换；搜索可用；恢复在线自动补同步 | |

## 备注 / 已知限制（记录用）

- **标签切换器形态**：只有标题按钮 + 下拉列表，没有常驻标签条；标签多时弹层最高 60vh、内部滚动，不设数量上限。
- **当前标签标记**：实现为整行浅蓝染底（`rgba(31,63,212,.08)`）+ 标题浅蓝加粗 + `aria-current="true"`，不是 spec §3.3 文字所述的圆点；视觉语义等价，留终审裁定是否回写规格。
- **同名文档**：切换器只显示标题，不同路径的同名文档在列表中视觉相同；关闭按钮的可访问名带标题，但肉眼无法区分（已知限制）。
- **切换器打开时顶栏不自动隐藏**（与 ⋯ 菜单同规则）；关闭 / 切换标签前会保存当前标签滚动位置。
- 提交 / 打开文档的深层链接行为不变；收藏、进度、高亮均按文档存储，不受标签影响。
- 高亮数据仅本机：清除站点数据会丢失，务必先导出备份（v1.1 既有限制，不变）。
- 字体体积大：不进 SW 预缓存，某档字体首次使用需联网（v1.1 既有限制，不变）。
- 本清单为验收用文档；回填时请同步更新头部「验收状态」与日期。
