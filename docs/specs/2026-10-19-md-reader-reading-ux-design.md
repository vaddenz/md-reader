- **日期**：2026-10-19
- **状态**：待用户评审
- **来源**：v1.2.0 真机验收反馈（4 项功能问题 + 3 项 UI 优化）。
- **关系**：本 spec 修订 `2026-10-19-md-reader-style-refresh-design.md`（下称样式 spec）的 §1.3-1（续读胶囊 → 回退为默认落位）、§3.1（首页细节）、§3.2（阅读页顶栏/底栏）；**视觉世界不变**（权威 = `DESIGN.md`：浅蓝 `#1F3FD4`、暖白纸面、分组卡语言）。

## 1. 功能修复（波1）

### 1.1 外观入口不再跳转设置页
- 现状：底栏「外观」点击 → 跳设置页外观区。
- 修订：底栏整体移除（§2.2），「外观」并入 ⋯ 菜单；点击后在**阅读页内**弹出外观面板（§2.5），不离开阅读上下文。
- 验收：⋯ → 外观 → 面板出现，URL 不变；调整实时作用于当前文档。

### 1.2 目录抽屉定位当前章节
- 现状：抽屉已有 `useScrollSpy` 激活态（`.toc-current`），但打开时始终从列表顶部显示。
- 修订：抽屉**打开时立即**将激活项滚动到可视区（居中偏上，不播放平滑动画）；激活项高亮沿用并强化（`--acc-text` + 加粗）。
- 验收：滚到文档中部 → 开目录 → 激活章节在可视区内且高亮。

### 1.3 ⋯ 菜单「横屏/旋转」不关闭菜单
- 现状：点「横屏」后菜单关闭；旋转后需重新唤出菜单才能切回。
- 修订：**横屏、旋转两项点击后菜单保持打开**（「旋转」项按方向就地出现/隐藏），支持连续操作；其余项点击后关闭（维持现行为）。
- 验收：⋯ → 横屏 → 菜单仍开 → 点「旋转」→ 回竖屏，期间无需二次唤出。

### 1.4 打开文档默认恢复阅读位置（回退胶囊方案）
- 修订：打开有进度的文档**默认跳转**到上次位置（恢复链：滚动记忆 → `?to=` → `?q=` → 进度比例，回到 v1.x 行为）；**移除「上次读到 N%」续读胶囊**（组件、样式、测试一并移除）。
- 说明：本项**推翻**样式 spec §1.3-1 的适配决定（依据：用户真机反馈「应默认跳转，而不是手动点击才跳转」）。
- 验收：有进度文档打开即落位（±5%）；无进度停在页首；`?to=`/`?q=` 分支不受影响。

## 2. 阅读页重构（波1，沉浸）

### 2.1 顶栏与自动隐藏（提案项，评审可砍）
- 顶栏：返回 · 标题 · ⋯（结构不变）。
- **自动隐藏（新增）**：正文向下滚动时顶栏上滑隐藏；向上滚动或回到顶部时显示；菜单/抽屉/面板打开期间不隐藏。无既有机制可沿用（v1.1 横屏沉浸仅涉及方向与菜单避让），本次新增。
- 若评审否决：顶栏常显，其余不变。

### 2.2 底栏移除
- 移除底部五项工具条（目录/搜索/外观/收藏/设置）及其固定占位。
- 正文底部预留由 108px 收紧至 ~32px；悬浮按钮（§2.3）浮于正文之上、不占布局。

### 2.3 悬浮目录按钮
- 形态：44px 圆角按钮（白卡 + 软影 + ☰ 线性图标），默认**右侧中部**（距右 12px、垂直约 55% 处）。
- 交互：点击开目录抽屉；**可拖拽**（拖动中半透明 + 轻微放大反馈）；松手水平吸附最近边缘（左/右 12px），垂直保持（clamp 于顶栏下方与底部安全区之间）。
- 位置持久化（按设备）；目录抽屉打开期间隐藏，关闭后恢复。
- 无障碍：`aria-label="目录"`，键盘可聚焦、Enter 触发。

### 2.4 ⋯ 菜单最终项集
顺序：**搜索 / 收藏 / 外观 / 文件 / 横屏 / 旋转 / 设置**。
- 每项带前导图标（18px 细线；外观为「Aa」文字徽；图标 `aria-hidden`，文字可访问名不变）。
- 关闭规则：横屏、旋转、收藏（就地切换类）点击后菜单保持打开；搜索、外观、文件、设置点击后关闭。
- 设置 = 跳转设置页（阅读页内唯一保留的跳转项）；搜索 = 跳搜索页；文件 = 开文件树抽屉。
- 收藏保持动态标签（收藏/取消收藏）。

### 2.5 外观面板（阅读内）
- 半屏底部 sheet（白卡、顶圆角 `--r-card`、软影），内容：**字体、正文字号、表格/引用比例**（沿用设置页外观区同款控件——抽取为共享组件，实时作用于当前文档；现有外观系统无「行距」项，不在本轮新增）。
- 亮度滑杆：**不加**（已确认）。
- 关闭：点击外部 / Esc（下滑手势不要求）。
- 与设置页外观区**共享同一偏好存储**（单源）。

### 2.6 返回语义（全站统一）
- 规则：**返回 / 取消 = 回到进入前的页面**；无应用内历史（直接打开 / 冷启动）时回首页。
- 适用：搜索页「取消」、设置页「返回」、阅读页顶栏「返回」（统一经 `goBackOrHome`：`history.state.idx > 0` → `navigate(-1)`，否则回首页）。
- 明确保留：阅读页「返回来源」（回正文互链来源）、文档缺失态「返回首页」（文案即目的地）、引导页保存完成回首页（前进完成流）、字体样张页「← 返回设置」（来源唯一）。

## 3. 多标签页（波2）

### 3.1 数据模型与持久化
- `tabs: [{ id, docPath, title, scrollY, ratio, openedAt }]` 与 `activeTabId`，存 prefs（kv），**跨重启恢复**（PWA 重开后标签仍在、激活标签恢复）。
- 每标签独立记忆滚动位置；文档级进度记录（首页「继续阅读」）照常工作。

### 3.2 打开规则
- 从首页 / 文件树 / 继续阅读 / 搜索结果点击文档：**总是新开标签**；该文档已打开 → 直接切到该标签（去重，同一文档仅一个标签）。
- 标签数不设硬上限；在切换器中关闭。

### 3.3 标签切换器
- 入口：点击顶栏标题（**始终可唤出**；标签 ≥2 时标题右侧出现 ▾ 指示；单标签时同样可唤出——用于关闭最后一个标签）。
- 形态：顶栏下方向下弹出的白卡列表（与 ⋯ 弹层同语言）；行 = 文档标题（单行截断）+ 关闭 ×；当前标签行标记（`--acc` 圆点）。
- 点击行 → 切换：保存当前标签位置、恢复目标标签位置（默认跳转语义，同 §1.4）。
- 关闭：点击外部 / Esc / 选中后。

### 3.4 关闭行为
- 关非当前标签：直接移除。
- 关当前标签：切到相邻（优先右、次左）；若为最后一个 → 返回首页（标签清空）。
- 关闭/切换前保存当前标签滚动位置。

### 3.5 与既有导航的关系
- 返回首页：回首页，标签保留；再次打开任一标签的文档 → 聚焦该标签。
- 搜索跳转（`?to=`/`?q=`）：按 §3.2 规则（新开/去重聚焦），锚点跳转在目标标签内生效。
- 文件树：点文件 → 关闭抽屉 + 新开/聚焦标签（保持现行为）。
- 收藏、进度、高亮按文档工作，不受标签影响。

### 3.6 边界
- 恢复时文档已不存在 → 丢弃该标签；存储损坏 → 清空标签，不阻塞启动。

## 4. 首页优化（波1）

### 4.1 继续阅读（横向卡片）
- 「继续阅读」改为**横向滚动卡片**：卡宽约 70%，内容 = 标题（≤2 行）+ 进度环（`--acc`）+ 「N%」；软影白卡。
- 与下方文件列表（竖向行式）形成明显区分；仅在有进度记录时出现。

### 4.2 文件列表分组与图标
- 根层分两组：**文件夹**（上）/ **文件**（下），组标签沿用现有组标签样式（「文件夹」「文件」）。
- 每行：线性图标（folder / file，`--ink2`）+ 名称；文件夹保留既有展开/收起。
- 排序：文件夹按名称、文件按名称（locale）；嵌套层级同样 folders-first + 图标。

### 4.3 同步信息弱化
- 「上次同步时间 + 更新目录」移至**页脚**：单行 12px `--ink2` 小字「上次同步 · N 分钟前」+ 小号刷新图标按钮（ghost）。
- 同步进行中状态保留但弱化；错误态仍以 `--danger` 文字可辨识。

## 5. 测试与兼容

### 5.1 e2e / 单测（波1）
- reader.spec：底栏用例改写（目录 → 悬浮按钮；搜索/收藏/设置 → ⋯；外观 → ⋯ 面板且不跳转）。
- 新增/调整：TOC 定位（§1.2）、横屏菜单不关（§1.3；orientation.spec 因菜单保持打开需微调收尾步骤）、恢复默认落位（progress.spec 由胶囊断言**回归**自动落位断言）、首页分组/页脚弱化（§4）。
- 悬浮按钮：拖拽后位置持久化（刷新仍在）、点击开目录。
- 顶栏自动隐藏（若保留 §2.1）：涉及 ⋯ 的既有用例在滚动后需先回到顶部/上滑唤出（实施时按需处理，不得弱化断言）。
- 结构契约保留：`.tree-item` 恒 3 等既有契约不得破坏；按钮 aria 名（返回/目录/搜索/收藏/设置/文件/横屏/旋转/更多）保留（返回语义见 §2.6；搜索取消以可见文案「取消」为名）。
- 单测：toc.test 等随动。

### 5.2 e2e（波2）
- 开 A → 开 B → 标题唤出切换器 → 回 A（位置恢复）；关当前 → 切相邻；重启恢复标签；同文档去重。

### 5.3 不变量
- 零数据迁移（prefs 新增字段缺省兼容）；离线/PWA 行为不破坏；暗色仍不做；无新增运行时依赖。
