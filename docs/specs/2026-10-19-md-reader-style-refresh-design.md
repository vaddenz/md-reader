# md-reader 样式焕新 · 设计方案（Style Refresh Spec）

> 日期：2026-10-19 · 状态：待用户评审
> 关系：本文件是 `docs/specs/2026-10-18-md-reader-design.md`（v1.0）与 `2026-10-18-md-reader-v1.1-design.md`（v1.1）的**视觉层增量**。功能、数据、同步、锚定、文案语义仍以原两份 spec 为权威；本文件只定义「看起来怎样」，以及三处显式标注的行为适配点。
> 方向契约：样张⑤「中文阅读器」（微信读书一脉，seed `e15d6207`），已由用户于五张样张中选定；工艺及格线 = 微信读书。

## 1. 概述

### 1.1 目标

全站视觉换装：阅读页、壳子/首页、设置页、组件细节（抽屉、浮层、toast、横幅、菜单、徽标），统一到选定方向的令牌系统下。

### 1.2 不变项（硬约束）

- 功能、路由、数据、同步、高亮锚定、搜索、离线逻辑：**零行为变更**（§1.3 两处显式例外除外）。
- 用户可见文案一律保持现有简体中文，不改语义；README/关于页的「仅供个人使用」声明保留。
- 既有测试全绿为底线；仅**断言随 token 变更的行**允许更新（见 §7）。
- 不引入新的运行时依赖；图标继续为手绘 SVG（单线宽、统一直角/圆角端点）。
- 未来方向约束：多仓库、阅读页多标签不被本次结构堵死（§6）。

### 1.3 显式行为适配点（需用户评审确认）

1. **「回到上次位置」胶囊**：样张⑤的签名时刻。落地后，打开文档**默认从头显示**，已保存的阅读位置以底部胶囊呈现、点击跳转——替代 v1.0 的「打开即自动跳到上次进度」。（若想保留自动恢复，删胶囊即回现状。）
2. **阅读页顶栏重组**：返回/标题/更多（⋯ 菜单：文件树、横屏、旋转）常驻顶栏；目录/搜索/外观/收藏/设置移入**底部工具条**。功能项一一对应，不增不减。

## 2. 设计令牌（全局）

### 2.1 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| `--page` | `#FAF9F6` | 阅读纸面 |
| `--shell` | `#F0EFEA` | 壳底（首页/设置/顶栏） |
| `--card` | `#FFFFFF` | 分组卡、面板 |
| `--ink` | `#17181A` | 主文字 |
| `--ink2` | `#5C6066` | 次文字（≥4.5:1 已核） |
| `--line` | `#E4E1DA` | 分隔线、描边 |
| `--acc` | `#0AA65A` | 强调填充（进度、开关、选中态） |
| `--acc-text` | `#077947` | 强调文字/链接（≥4.5:1 已核） |
| `--acc-fill` | `#078A4E` | 实心按钮（白字 ≥4.5:1 已核） |
| `--hl-yellow` | `#FFF1A8` | 持久高亮·黄 与 `==高亮==` |
| `--hl-red` | `#FFD9D4` | 持久高亮·红 |
| 搜索命中 | `rgba(10,166,90,.22)` + 1px 绿下划线 | 与持久高亮区分（改 token，见 §7 断言更新） |
| `--danger` | `#C0392B` | 错误、危险区 |
| 状态语义色 | 保留现义（同步/离线/错误/过期） | 与新底色重新校验对比度后微调明度，不改语义 |

- `:focus-visible`、文本选区、光标、滚动条、下划线偏移一律从令牌取色（craft floor 要求）。
- 暗色/夜间：**不在本次范围**（样张⑤为浅色世界）。

### 2.2 字体与排版

- 字体栈不变（系统中文无衬线 + 既有三档可选字体与 `--r-*` 变量体系）。
- 正文：17px / line-height 1.9（1.8 → 1.9 的唯一调整）；标题层级、表格、引用、代码的既有比例体系不动。
- 数字一律 `tabular-nums`（列表计数、百分比、元信息）。

### 2.3 形状与海拔

- **单层海拔原则**：卡片 = 圆角 14 + 软影 `0 6px 18px rgba(40,44,52,.10)`，**不再叠边框**；行与行之间用 1px `--line`。
- 按钮圆角 10；药丸（22）只给小控件（胶囊、chip）；模态/抽屉顶 16。
- 节奏：卡内行距紧（12–13px），组间距宽（≥14px）；标题上间距 > 下间距。

## 3. 分屏设计

### 3.1 壳子 / 首页

- 顶栏：标题「知识库」居中 + 右侧 ⚙ 直达设置（样张的左 ☰ 无对应功能，**不保留**——诚实适配）。
- 搜索框（灰底圆角 10）置顶；其下「继续阅读」软影卡：进度绿点 + 标题 + 绿进度条 + 百分比。
- 文件树改为**分组列表**：组标签（篇数，tabular）+ 软影分组卡（行：标题 + 时长/状态 + chevron）；未缓存/陈旧行文字退至 `--ink2`。
- 同步徽标保留在搜索框同排或组标签行末端，功能与交互不变。

### 3.2 阅读页

- 顶栏：返回 · 标题（单行截断）· ⋯（更多）菜单 = 文件树 / 横屏 / 旋转（三项现有功能平移）。
- 正文区：纸面 `--page`；标题、元信息行（tabular）、高亮/引用/表格/代码按 §2 令牌；**底部工具条**：目录 / 搜索 / Aa（跳转设置「阅读外观」，不新增浮层面板）/ 收藏 / 设置，高度 74px、毛玻璃底 `rgba(250,249,246,.96)`；正文底部预留 108px 内边距防遮挡。
- 「回到上次位置」胶囊（§1.3-1）：深底 #17181A 白字，含绿点，居中悬浮于导航下方，仅在存在已保存进度且位置 > 首屏时出现。
- 目录/文件树抽屉：保留既有交互与位置，改用壳底色 + 软影 + 16px 顶圆角；选中项用绿点/绿字，不改信息结构。
- 右键/长按菜单：白卡圆角 12 + 软影，行高亮底灰，主操作绿字（复制/高亮/清除/全选的项集与行为**完全不变**）。

### 3.3 设置页

- 所有区块改为 iOS 式**分组卡**（组标签在上、软影卡承载行）：访问 Token / 仓库配置 / 同步 / 存储 / 阅读外观 / 高亮数据 / 显示方向 / 危险区 / 关于——九个区块全部迁移，顺序与文案不变。
- 控件：单选行 = 右侧 ●/空心圆 + 选中整行微高亮；滑杆 = 绿轨道钮 + 灰轨；按钮 = 实心绿主按钮 / 灰底幽灵按钮；危险区按钮 = `--danger` 文字按钮。
- 提示/错误行：错误用 `--danger`，成功用 `--acc-text`，其余 `--ink2`。

### 3.4 全局细节

- Toast：深底圆角胶囊（与「回到上次位置」同族），错误态用 `--danger` 底白字。
- 离线横幅：壳底 + 状态点橙（语义保留）；同步中/失败徽标沿用既有语义色，重新校验对比度。
- 图片、mermaid 占位、代码块：统一白卡/浅灰底圆角 10；代码块深底 #1B1D21 保留（语法高亮配色微调以适配深底）。
- 空态、加载态、错误态：以「纸面 + 居中文字 + 单个主按钮」呈现，不引入新插画语言。

## 4. 视觉底线（craft floor 摘要）

正文与占位文字对比 ≥4.5:1、大字 ≥3:1；海拔只声明一次；正文行宽 65–75ch；字距不低于 -0.04em；无 kicker/编号标签；无 emoji 图标（全部手绘 SVG 同一 1.9–2 线宽）；卡片同尺寸堆砌不用作页面结构；文字选区/光标/滚动条/焦点环全部主题化。

## 5. 未来兼容（多仓库 / 多标签）

- 不设计未来功能，但结构不得堵死：顶栏「返回 · 标题 · 更多」不与未来「标签条」冲突（标签条为顶栏下方独立行）；首页分组列表的组标签体系可自然扩展为「仓库 → 目录」两级；设置页分组卡可插入仓库配置组。
- 令牌层面：仓库/标签的未来色（如每仓库一个标识色）不占用 `--acc` 主色。

## 6. 实施与流程

1. 本 spec 经用户评审 → `docs/plans/` 实施计划 → `style-refresh` 工作区（分支 `style-refresh`）子代理驱动实施 + 两阶段审查。
2. e2e 断言随 token 更新清单：`mark.hl-yellow` 计算背景 `rgb(255,235,59)`→`rgb(255,241,168)`；`mark.hl-red` `rgb(255,138,128)`→`rgb(255,217,212)`；其余样式断言按实现核对。
3. 收尾（impeccable 工艺门）：构建后运行设计检测器 `detect.mjs` → 批量修复 → 复核；真机验收清单（在既有清单基础上追加视觉项）；`DESIGN.md` 记录建成的世界（documenter 口径）；最后合回 `main`。

## 7. 非目标

- 不改任何功能/数据/文案语义（§1.3 两处例外外）；不加暗色模式；不加新特性（Aa 浮层面板、标签、仓库切换均不做）；不动字体文件与同步/锚定逻辑；不引入新依赖。

## 8. 风险与开放问题

| 风险 | 缓解 |
| --- | --- |
| 样张未覆盖的态（空/错/加载/离线/菜单） | 按令牌推导实现，验收清单逐项过 |
| e2e 视觉断言更新遗漏 | §6 断言清单 + 全量回归 |
| 绿色强调与既有状态色冲突 | §2.1 状态语义保留 + 对比度复核步骤 |
| 底部工具条与安卓手势条/横屏全屏的遮挡 | 工具条内含安全区 padding；真机验收含横屏态 |
