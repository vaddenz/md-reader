## 多标签

- [ ] **历史语义**：`activateTab`/`close` 使用 push；关标签后按返回会把已关标签重新登记；N 次切换需 N 次返回才穿出。建议关闭/切换改 `replace`，或明确「返回跳过标签切换历史」。
- [ ] 标签切换后「返回来源」丢失（`location.state.from` 不随标签持久化）。
- [ ] 焦点归还：Escape 关闭切换器、关闭非当前标签后焦点落 body。
- [ ] 跨窗口不广播：另一浏览器标签页仍持旧标签，可写回新库（既有缺口）；`openDb` 自愈（删库重建）不派发 `data-cleared` 事件。
- [ ] 当前文档被 prune 后会立即 re-add（missing 态可关闭）；同名文档在切换器里不可区分（清单已备注）。
- [ ] 数据层：`EMPTY_TABS` 共享单例；纯空白标题可通过；时间基 id 跨重启同毫秒理论碰撞；`sanitizeTabs` 不去重 id；`pruneMissing` 以长度判等。
- [ ] 同 tick 双 close 会互相覆盖（离散事件不可达）；`tabsRef.current` 渲染期写入（惯例，低风险）。
