# 文字笔记真机验收清单（v1.8）

> 日期：2026-10-21 · 验收环境：安卓手机 PWA（主屏幕应用）+ 桌面浏览器。
> 前置：已配置 GitHub Token 并能打开文档；如需验证同步，按 [`docs/sync-neon-setup.md`](sync-neon-setup.md) 启用 Neon Data API。
> 通过标准：以下逐项通过；任一项不通过则记录现象与复现步骤后回到修复。
> 设备约定：**A** = 主要使用设备；**B** = 第二台设备或另一个干净的浏览器 profile。

## 1. 创建与锚点

- [ ] 选中一段普通正文，长按/右键菜单出现「复制 / 笔记 / 高亮·黄 / 高亮·红」。
- [ ] 点击「笔记」打开「添加笔记」面板，引用区显示所选原文，输入框自动聚焦。
- [ ] 空内容时「保存」不可用；输入文字后保存，面板关闭并提示「笔记已保存」。
- [ ] 锚定文字末尾出现蓝色便签符号；正文文本、换行、复制内容不受影响。
- [ ] 在同一段文字上再建一条笔记：出现两个符号，两条记录互不覆盖。
- [ ] 选区内含代码块等排除区时，菜单只提供「复制」，不提供「笔记」。

## 2. 查看与编辑

- [ ] 点击锚点符号打开「编辑笔记」，内容与之前保存一致，输入框光标在正文末尾。
- [ ] 修改后保存，列表与符号仍在；刷新 / 重启 PWA 后笔记与符号保留。
- [ ] `⌘/Ctrl+Enter` 可保存；Esc、遮罩、关闭按钮可关闭；关闭后焦点回到原触发位置。
- [ ] 编辑面板打开期间背景不滚动，手机上不被软键盘遮挡操作按钮。

## 3. 文档笔记列表

- [ ] 顶栏 `⋯` 菜单出现「笔记」，有笔记时显示数量，如「笔记（2）」。
- [ ] 点击后从底部弹出「笔记」抽屉，条目按正文位置从前往后排列。
- [ ] 每条显示原文摘录、笔记正文与相对时间；点击条目打开对应编辑面板。
- [ ] 无笔记时显示空态说明，可从选区菜单添加。
- [ ] 手机上抽屉内可滚动，条目触控目标正常，无横向溢出。

## 4. 重锚与孤儿

- [ ] 在仓库中修改文档（在锚定文字前后增删段落）→ 更新目录 / 同步 → 重新打开文档，符号仍跟随原文。
- [ ] 改写锚定文字本身 → 更新后符号消失，但 `⋯ › 笔记` 列表仍能看到该笔记，并标记「原文已改动」。
- [ ] 把原文改回 → 重开后符号恢复。
- [ ] 孤儿笔记仍可打开编辑与删除。
- [ ] 同时存在高亮与笔记：黄/红高亮与符号都正常显示；清除高亮后笔记符号仍在。

## 5. 删除

- [ ] 点击符号 → 「删除」→ 确认后符号消失，列表中该条消失。
- [ ] 刷新后不复活。
- [ ] 删除一条笔记不影响同文档其它笔记。

## 6. 跨设备同步

在 A 上创建两条笔记（其中一条编辑一次），手动同步；在 B 上用同一接口地址与 JWT 手动同步：

- [ ] B 打开同一文档，两条笔记的锚点符号、正文、时间与 A 一致。
- [ ] B 编辑其中一条 → 同步 → A 同步后看到更新后的正文；较旧设备不会把新内容覆盖回旧版。
- [ ] A 删除一条 → 同步 → B 同步后该条消失，且不会因旧 outbox 复活。
- [ ] 两台设备同时离线修改同一条：联网后按较新时间戳获胜；不同笔记互不覆盖。
- [ ] 新建 / 编辑 / 删除笔记后，同步页「待同步条数」增加；点击「立即同步」后清零。
- [ ] 同步范围卡包含「笔记」；不同步正文、Token、AI Key、训练会话、标签页、阅读外观。

## 7. 回归

- [ ] 选中文字 → 复制 / 高亮 / 清除高亮 / 全选行为与之前一致。
- [ ] 搜索直达、目录、文件树、返回来源、滚动恢复、阅读进度正常。
- [ ] 多标签切换后各文档笔记互不串；切换文档时笔记面板/抽屉自动关闭。
- [ ] 多仓库切换后笔记按仓库独立显示。
- [ ] 「清除全部数据」确认文案包含高亮与笔记；执行后回到引导页。
- [ ] `npm run typecheck` / `npm test` / `npm run build` / `npm run test:e2e` 全绿。
